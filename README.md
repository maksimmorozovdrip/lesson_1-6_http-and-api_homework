# Витрина фильмов
frontend показывает коллекцию фильмов из собственного REST API и позволяет добавить новый фильм через форму.

## Тема и endpoint

- Тема: фильмы
- Ресурс: `movies`
- Endpoint: `http://localhost:3000/movies`

Поля фильма: `title` (строка), `director` (строка), `year` (число), `rating` (число), `watched` (да/нет).

## Что реализовано

- загрузка списка через `GET` с состояниями: загрузка, список, пустой список, ошибка;
- кнопка «Обновить», которая заново выполняет `GET`;
- форма с валидацией и отправка новой записи через `POST`;
- после успешной отправки список загружается с сервера заново.

## Запуск

1. Запустить API:

```
   cd backend
   npm ci
   npm run dev
```

2. Проверить в браузере: http://localhost:3000/movies
3. Открыть `frontend/index.html` через Live Server.
